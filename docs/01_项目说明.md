# Megakernel 主线设计说明

## 0. 一句话

mainline 只保留一个 `decode_backend="megakernel"`：新的 task-graph
Megakernel。对照路径是同一个 nano-vLLM 引擎中的 `torch-cudagraph`。

旧的 `kernel.cu` persistent/WMMA 实现已保存到 Git 分支
`codex/archive/frozen-kernel`，不再参与当前构建、调度或 benchmark。

## 1. 三层结构

```text
LLMEngine
  ├── Scheduler / BlockManager
  ├── ModelRunner
  │    ├── torch eager / CUDA Graph（prefill + fallback decode）
  │    └── MegakernelBackend（decode-only task graph）
  └── MetricsCollector
```

### 1.1 集成边界

- prefill 始终由 nano-vLLM torch 模型执行；
- Megakernel 只接管 greedy decode；
- task graph 每个 decode step 发起一次 whole-batch cooperative launch；
- `TG_MAX_BATCH=8` 是 scratch/bar 的编译期容量上限；
- 不支持 sampling、TP、多模型结构或超过 2048 的上下文。

### 1.2 代码布局

- `backends/megakernel/backend.py`：Qwen contract、compatibility、engine adapter；
- `backends/megakernel/taskgraph.py`：schedule/scratch/bar 生命周期；
- `backends/megakernel/schedule.py`：指令流和依赖计数器生成；
- `backends/megakernel/weights.py`：权重视图、RoPE 表、11 指针结构打包；
- `backends/megakernel/csrc/taskgraph_kernel.cu`：CUDA worker/controller kernel；
- `backends/megakernel/csrc/torch_bindings.cpp`：只注册 `tg_decode_step` 和
  `tg_zero_regions`。

## 2. Decode 数据流

```text
Scheduler.schedule()
  -> ModelRunner.prepare_decode()
  -> MegakernelBackend.decode()/decode_batch()
       -> TaskGraphDecoder.decode_rows()
            -> zero scratch + bars
            -> stage embedding into x_resid
            -> one tg_decode_step cooperative launch
            -> copy sampled token ids to host
  -> Scheduler.postprocess()
```

Megakernel 直接使用 nano-vLLM 分配的 paged KV cache：

```text
[2, num_layers, num_blocks, block_size, num_kv_heads, head_dim]
```

当前 token 的 cache contract 是 `cache_len = position + 1`；block table 的
padding 使用物理 block 0，不能使用 -1。

## 3. Baseline

| backend | 用途 |
|---|---|
| `torch` + `enforce_eager=True` | host-bound 下界 |
| `torch` + `enforce_eager=False` | 主要 CUDA Graph 对照 |
| `megakernel` | 当前 task-graph 实现 |

## 4. 正确性和 profiling

- correctness：`PASS / CASCADE / FAIL`；
- cooperative kernel：用 `nsys`，不要用 `ncu`；
- ABI：`tg_abi.h`、`schedule.py`、`torch_bindings.cpp`、CUDA kernel 必须同步；
- GPU 主验证：`RUN_MODE=taskgraph-baseline bash SERVER_COMMANDS.txt`。
