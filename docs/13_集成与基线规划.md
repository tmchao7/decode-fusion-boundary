# Task-Graph Megakernel 主线集成与基线

> **状态**：现行 —— 主线集成范围与基线定义。

> 更新日期：2026-09-24

## 1. 主线目标

主线只比较：

```text
torch-eager       -> host-bound 下界
torch-cudagraph   -> 主要 GPU 对照
megakernel        -> task-graph 实现
```

旧的 `megakernel-tg` 只是接入阶段的临时名称，已经正式收敛为
`megakernel`。旧 `kernel.cu` 线保存于 `codex/archive/frozen-kernel`。

## 2. 集成架构

```text
ModelRunner.run()
  -> 预填充：torch model
  -> decode：MegakernelBackend
       -> TaskGraphDecoder.decode_rows()
            -> 清 scratch/bars
            -> host staging embedding
            -> tg_decode_step cooperative launch
            -> 一次 token-id D2H
```

task graph 不接管 scheduler 的 prefill，不增加第二套 KV cache，也不引入旧
Megakernel 的 burst 或 batch-kernel 开关。

## 3. 批次和 workload

```text
batch:       1, 2, 4, 8
prompt:      32, 512, 1920
max_tokens:  128
warmup/runs: 2/3
```

端到端 benchmark 必须满足 `prompt + max_tokens <= 2048`。内核微基准可以单独
使用 context 2048。

## 4. 阶段状态

### 阶段 0：主线收敛和基线

已完成：

- `decode_backend="megakernel"` 指向 TaskGraphDecoder；
- 删除旧 backend/burst 配置和生产调用链；
- extension 只编译 `taskgraph_kernel.cu` + task-graph bindings；
- benchmark 默认只包含两个 torch controls 和一个 Megakernel；
- tests、server commands、README 与交接文档统一命名。

待服务器完成：

```bash
RUN_MODE=taskgraph-baseline bash SERVER_COMMANDS.txt
```

### 阶段 1：task graph 性能

基于新基线再决定是否继续：

- split-K 的确定性归约；
- A staging 与权重 pipeline；
- attention 向量化；
- 更细的跨 SM 软件流水。

### 阶段 2：连续 batching

只有阶段 1 证明单步 device 时间值得继续后，才考虑 slot 管理、geometry
切换、KV pressure 和 prefill/decode 交替。

## 5. Phase 0（服务器前）已落地

- prefill 继续使用现有 FlashAttention varlen，不重写 FlashAttention；
- scheduler 支持 `max_prefill_tokens_per_step` 和 `prefill_decode_ratio`，
  为后续 mixed prefill/decode 做公平性基础；
- KV/block manager 提供运行时 cache 统计；
- batch=1 Megakernel metadata staging 复用持久 host/GPU row table；
- 新增 CPU-only contract tests，服务器前可验证接口和生命周期。

## 6. 硬约束

1. cooperative kernel 不使用 `ncu`；
2. task-graph ABI 的字段顺序、bar 计数和 instruction width 必须保持同步；
3. correctness 使用 PASS/CASCADE/FAIL；
4. 新 backend 名称必须同步更新 config、backend、compare、correctness 和
   SERVER_COMMANDS；
5. 历史 kernel.cu 数字只能作为 archive/reference，不得混入新基线。
